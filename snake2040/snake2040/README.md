# SNAKE 2040 — Ақылды жылан

Автор: **Бейсен Ерасыл** · Технологиялар: HTML, CSS, JavaScript (Canvas, LocalStorage, Web Audio)

## Қалай іске қосу
`index.html` файлын браузерде ашыңыз (үш файл бір қалтада болуы керек: `index.html`, `style.css`, `script.js`).

## Басқару
| Перне | Әрекет |
|---|---|
| W A S D / ← ↑ ↓ → | Жыланды басқару |
| Space | Бастау / тоқтату / жалғастыру |
| R | Қайта бастау |
| Tab, Enter | Батырмалар мен параметрлерге өту |

## Негізгі мүмкіндіктер
- Әр алма +1 ұпай, әр 5 ұпай сайын жылдамдық артады және жаңа жарық эффектісі (түс пен бөлшектер) шығады.
- 3 қиындық деңгейі: Оңай, Қалыпты, Қиын.
- Жыланның 3 түстік схемасы, дыбысты қосу/өшіру.
- Рекорд және Топ-5 рекордтар тақтасы (LocalStorage).
- Телефонға арналған бағыт батырмалары және свайп.

## Қолжетімділік (WCAG 2.2)
- Барлық функция тышқансыз орындалады; фокус индикаторы анық (4 px көк контур).
- Семантикалық HTML: `header`, `main`, `section`, `footer`, `h1–h3`, `label`, `fieldset`.
- Canvas-қа `role="img"`, `aria-label` және оқиғалар кезінде жаңартылатын `aria-describedby` мәтіндік баламасы бар.
- NVDA үшін бір ғана `role="status"` + `aria-live="polite"` аймағы. Хабарламалар тек оқиғада беріледі (басталу, алма, жылдамдық, тоқтату, жалғастыру, аяқталу, рекорд). Қайталанатын хабарламалар сүзіледі, әр секунд сайын хабарлама жоқ.
- `prefers-reduced-motion` ескерілген: пульсация, бөлшектер, жарық және CSS анимациялары өшеді.
- Түс контрасты: мәтін мен батырмада қою көк `#14163a` ашық фонда; ойын алаңы қою фонда ашық түстер. Статус түстен басқа мәтінмен де беріледі.
- Мақсатты өлшем: батырмалар кемінде 48×48 px.

## ЖИ қолдану
Жобада жасанды интеллект көмекші құрал ретінде қолданылды. Төмендегі промпттарды өзіңіз қолданған нақты мәтінмен ауыстырыңыз.

1. **Промпт 1 (жалпы жоба):** «HTML, CSS және JavaScript арқылы қазақ тіліндегі, ашық түсті, креативті, толық қолжетімді SNAKE 2040 ойынын жаса. Файлдар: index.html, style.css, script.js. W A S D және бағыттауыш пернелер, Space, R, LocalStorage рекорды».
2. **Промпт 2 (қолжетімділік):** «NVDA үшін aria-live="polite" және role="status" қолданып, тек маңызды оқиғаларды қазақша хабарла: ойын басталды, алма жедіңіз, жылдамдық артты, тоқтатылды, жалғастырылды, аяқталды, жаңа рекорд. Әр секунд сайын хабарлама берме».
3. **Промпт 3 (тексеру):** «Кодты WCAG 2.2 бойынша тексер: фокус, контраст, prefers-reduced-motion, Canvas мәтіндік баламасы, пернетақтамен басқару. Қателерді тізімде».
